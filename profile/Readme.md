### 🚀 About Quantitive Engineering LLC

**Quantitive Engineering LLC** (`الكمية للهندسة ش.ش.و`) is a multidisciplinary engineering, industrial automation, and open-source software development firm headquartered in **Muscat, Oman**. 

Guided by our motto — **"Draw, Design & Develop"** — we bridge the gap between physical industrial hardware and modern cloud-native software. We architect sovereign, self-hosted enterprise ecosystems, AI-driven computer vision surveillance, and resilient cloud infrastructures that eliminate vendor lock-in and empower organizations across the GCC.

### 📂 Repository Directory & Organization

Our repositories are structured across four primary engineering tracks:

* **`erp-and-business-apps`** — Custom Frappe/ERPNext applications (`quantitive_core`), custom print formats, Omani localization modules, and POS/E-Commerce integrations.
* **`ai-and-automation`** — Model Context Protocol (MCP) servers, multi-agent orchestration scripts, n8n workflow templates, and RF-DETR computer vision pipelines.
* **`cloud-and-devops`** — Infrastructure-as-Code, Docker Compose stacks, Nginx/Caddy reverse-proxy configs, automated S3 backup scripts, and hardened mail server deployments.
* **`web-and-mobile`** — Responsive corporate web portals, React/Tailwind UI components, and cross-platform Flutter applications.
